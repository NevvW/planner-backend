## 1) На что выдается `refreshExp` при логине?

`refreshExp` — это время истечения именно **refresh token / refresh session**, а не access token.

- `access_token` — короткоживущий токен доступа;
- `refresh_token` — токен для обновления access token;
- `refresh_exp` — момент, до которого текущий refresh token еще валиден.

Аналогично и в `RefreshResponse`: после ротации refresh token сервер возвращает новый `refresh_token` и новый `refresh_exp`.

## 2) Критерии успешной регистрации пользователя

Регистрация считается успешной, если одновременно выполнены следующие условия:
1. `email` передан и проходит валидацию как корректный email.
2. Длина `email` не превышает `254` символа.
3. `password` передан.
4. Длина `password` от `8` до `72` символов.
5. После `TrimSpace` email не пустой.
6. репозитории успешно создан новый пользователь.
7. Email не занят другим пользователем.
8. Сервер возвращает 200 на `POST /v1/register`.
9. `RegisterResponse` если возвращается `user_id` значит, что пользователь создан в БД и ему присвоен идентификатор.
